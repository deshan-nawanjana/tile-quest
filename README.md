# Tile Quest: Sliding Picture Puzzle Game

The sliding puzzle is a very popular game in childhood. It is a square-shaped picture divided into a grid with one tile removed, leaving an empty space. The player slides the tiles horizontally or vertically into the empty space to rearrange them and restore the original picture. This app includes a module to generate and make the puzzle move as a two-dimensional array.

Launch Now: [https://deshan.lk/apps/tile-quest](https://deshan.lk/apps/tile-quest)

## Key Features

- Play sliding puzzle with arrow keys on desktops and finger swipes on mobile.
- Vary puzzle difficulty by adjusting the number of pieces.
- Select or upload different images.
